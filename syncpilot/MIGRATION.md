# Contract compatibility

The public source retains contract versions 1–5. Validate a configured contract with the engine before use. Do not silently upgrade received contracts or rewrite historical evidence.

Version 5 identifies participant projects and qualifies individual actors per operation. A conversation fork requires its own source identity. Existing request, actor, operation and nonce formats remain unchanged by the source qualification helper.

Old project_sync.py filenames and project-sync.json contracts remain format compatibility details. The plugin and skill identities are syncpilot. Any migration of a live installation, transport, registry or destination requires the adopter's own qualified mandate and independent native checks.
